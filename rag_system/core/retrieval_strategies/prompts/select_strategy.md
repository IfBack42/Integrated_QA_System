可选策略只有以下四种：

1. 直接检索
   适合：问题目标清楚，包含明确实体、术语、章节、人物或事实。

2. 假设答案检索
   适合：问题较抽象或表达很短，直接关键词不容易对应知识库原文；先生成一段可能出现于资料中的假设答案，再用它检索。

3. 子查询检索
   适合：一个问题明确包含多个对象、多个条件或多个需要分别回答的方面。

4. 回溯问题检索
   适合：问题依赖更基础、更宽泛的背景知识；需要先检索上位概念，再结合原问题检索。

选择规则：
- 能直接检索时优先“直接检索”，不要为了复杂而选择增强策略。
- 只有明确包含多个检索目标时才选择“子查询检索”。
- “回溯问题检索”不是简单改写，而是补充原问题依赖的背景问题。
- 只输出一个完整策略名称，不要解释，不要添加标点或编号。
